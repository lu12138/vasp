Environment

环境搭建

给新手准备的免费/开源工具入口，用于结构查看、输入文件生成和结果后处理。

VASPKIT

面向 VASP 原始计算数据的用户友好型预处理与后处理工具，可在交互界面或命令行模式下运行。

VESTA

用于电子和结构分析的三维可视化系统，可显示结构模型、体数据和晶体形貌。

pymatgen

Python Materials Genomics，开源材料分析库，提供结构、分子、组成等核心对象和多种电子结构程序文件读写能力。

ASE

Atomic Simulation Environment，一组用于搭建、操作、运行、可视化和分析原子模拟的 Python 工具与模块。

phonopy

开源声子计算包，用于谐近似和准谐近似层级的声子计算，可输出声子能带、DOS 和热力学性质。

Bader

基于电子电荷密度划分原子的电荷分析方法，常用 Bader 体积中的电荷近似表示原子的总电子电荷。

Bash

常用 Bash 代码

面向 VASP 计算的常用命令片段，复制后按自己的队列系统和目录名修改。

vasp-common.sh 常用 VASP Bash 片段
# Basic: 常用基础命令
pwd # 显示当前所在目录
ls # 列出当前目录下的文件和文件夹
ls -lh # 以可读大小显示文件列表
cd 01_relax # 进入 01_relax 文件夹
cd .. # 返回上一级目录
mkdir test # 新建 test 文件夹
cp CONTCAR POSCAR # 复制 CONTCAR 并命名为 POSCAR
mv CONTCAR CONTCAR_relaxed # 重命名文件
rm WAVECAR # 删除 WAVECAR 文件，删除前确认不再需要
less OUTCAR # 分页查看 OUTCAR 文件
tail -n 20 OSZICAR # 查看 OSZICAR 最后 20 行
grep "F=" OSZICAR # 搜索 OSZICAR 中的离子步能量行
vasp_std # 直接运行标准版 VASP，适合交互节点测试
mpirun -np 16 vasp_std # 使用 16 个 MPI 进程运行 VASP
sbatch job.sh # 使用 Slurm 提交当前目录的任务
squeue -u $USER # 查看自己正在排队或运行的任务
# Advanced: 计算检查与结果提取
grep "reached required accuracy" OUTCAR # 检查离子步是否达到收敛标准
grep "F=" OSZICAR | tail -n 5 # 查看最后 5 个离子步总能
grep "E0=" OSZICAR | tail -n 1 # 查看最后一步外推总能
grep "energy without entropy" OUTCAR | tail -n 1 # 提取最终无熵修正能量
grep "Elapsed time" OUTCAR # 查看本次计算耗时
# Advanced: 批量提取能量
for dir in */; do # 遍历当前目录下所有子目录
test -f "$dir/OSZICAR" || continue # 没有 OSZICAR 的目录直接跳过
energy=$(grep "F=" "$dir/OSZICAR" | tail -n 1 | awk '{print $5}') # 提取最后一步自由能
printf "%-28s %s\n" "$dir" "$energy" # 按目录名和能量两列输出
done > energy_summary.dat # 保存结果到 energy_summary.dat
# Advanced: 优化后转静态计算
cp 01_relax/CONTCAR 02_static/POSCAR # 将优化后结构作为静态计算输入
cp 01_relax/POTCAR 02_static/POTCAR # 复用相同 POTCAR，保持元素顺序一致
cp 01_relax/KPOINTS 02_static/KPOINTS # 先复用 KPOINTS，必要时再加密
cp INCAR_static 02_static/INCAR # 使用静态计算专用 INCAR
cd 02_static # 进入静态计算目录
# Submit: 批量提交任务
for dir in 01_relax 02_static 03_band; do # 指定需要提交的计算目录
test -d "$dir" || continue # 目录不存在时跳过
test -f "$dir/job.sh" || continue # 没有提交脚本时跳过
(cd "$dir" && sbatch job.sh) # 进入目录并用 Slurm 提交任务
done # 完成所有目录的提交

POSCAR

POSCAR 准备流程

先确定结构来源，再完成建模、格式转换和最终检查。POSCAR 的元素顺序必须和 POTCAR 合成顺序一致。

01

获取结构

晶体优先下载 CIF；分子优先下载 SDF、MOL 或 XYZ。

02

建模处理

按任务建立原胞、超胞、表面、缺陷、吸附或分子盒子。

03

转换 POSCAR

用 VASPKIT、pymatgen 或 ASE 转成 VASP 输入结构。

04

检查后使用

检查元素顺序、晶胞、坐标、真空层、固定原子和原子重叠。

Crystal CIF

晶体结构下载

  • Crystallography Open Database免费开放 CIF，适合找实验晶体结构。
  • Materials Project常用计算材料数据库，下载结构前注意材料编号和相稳定性。
  • AFLOW适合补充查找晶体结构和计算材料条目。

Molecule

化学结构下载

  • PubChem下载 2D/3D 分子结构，常见格式包括 SDF。
  • NIST Chemistry WebBook查分子信息、热化学和谱学数据。
  • ChemSpider适合按名称、CAS 或式量补充检索分子结构。

Convert

转换与检查工具

  • VASPKIT生成 VASP 输入、建表面、转格式、检查结构。
  • pymatgen适合脚本化读取 CIF、生成超胞和写出 POSCAR。
  • ASE支持多种结构格式读写，可自动化批量转换。

Materials Studio

MS 建模流程

  1. 导入 CIF，先检查晶格、元素、占位和对称性。
  2. 按任务建立超胞、slab、缺陷、替位、间隙或吸附构型。
  3. 表面模型设置足够真空层，必要时固定底层原子。
  4. 分子吸附先放多个初始位点，避免初始距离过近。
  5. 导出 CIF、XSD 或 CAR，再用 VASPKIT、pymatgen、ASE 转成 POSCAR。

Checklist

注意事项

  • 不要直接信任无序结构、部分占位和含溶剂 CIF，先清理再计算。
  • POSCAR 元素行顺序必须和 POTCAR 顺序一致。
  • 吸附、缺陷、表面能等能量差计算要保持相同精度和可比模型。
  • 磁性、价态、电荷态、偶极修正不会由 POSCAR 自动决定，需要在 INCAR 中设置。
  • 最终打开结构确认没有原子重叠、真空层不足或坐标越界问题。

KPOINTS

KPOINTS 设置指导

KPOINTS 控制布里渊区采样。正式计算前先做收敛测试；做能量差比较时，相关模型应使用可比的采样精度。

01

体相晶体

三维周期结构使用 3D 网格，例如 5 5 5、7 7 7。金属和小晶胞通常需要更密网格。

02

表面与二维材料

真空方向通常设为 1，例如 5 5 1。只在有周期性的方向增加 K 点。

03

分子与孤立团簇

大真空盒中一般使用 Gamma only，即 1 1 1，并重点检查盒子尺寸。

04

能带路径

先用普通网格完成静态自洽，再用 Line-mode 高对称路径做非自洽能带计算。

Workflow

使用流程

  1. 先固定 ENCUT，测试 3 3 3、5 5 5、7 7 7 等 K 点网格。
  2. 观察总能、力、带隙、吸附能或目标性质是否稳定。
  3. 表面、吸附、缺陷、替位等能量差计算保持同一套采样规则。
  4. DOS 用更密网格；能带用静态 CHGCAR 加 Line-mode KPOINTS。

经验检查

  • 能量差任务不要让不同模型的 K 点密度相差太大。
  • 晶胞越大，所需 K 点数通常越少；原胞越小，所需 K 点数通常越多。
  • 金属体系对 K 点更敏感，需同时关注 ISMEAR 和 SIGMA。
  • 使用 KSPACING 时要记录取值，保证后续任务可复现。
